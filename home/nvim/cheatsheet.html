Text objects · mini.ai

<a> = around (includes delimiters) · <i> = inside. Daemonize with c, d, y, g=… e.g. daw = delete a word.

the core set

a / i +wword
WWORD (no punct)
'backtick
q / Q" / ' quotes
(parens
[square brackets
{curly braces
t / Ttag / tag name
f / Ffunction call / def
a / iargument
ccomment
ssentence
iindentation
gwhole buffer
xdigits / numbers
uURL
Bracket shorthand is inherited: aB = around braces, ab = around square brackets, a( = inside parens… all work with counts & operators.
