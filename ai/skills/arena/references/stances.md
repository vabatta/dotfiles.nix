# Stances

Give each writer one stance. Pick the ones that pull furthest apart for this artifact. Diversity across whole shapes is the point, not variations inside one shape.

| Stance | Optimises for | May ignore |
|---|---|---|
| Minimalist | The fewest concepts, lines, and moving parts that meet the definition of done | Future needs nobody has asked for |
| Textbook | The well-known pattern done properly, as an expert in the field would | Novelty |
| Inversion | The opposite of the obvious answer: invert the control, the ownership, or the data flow | Convention |
| Borrowed | How another ecosystem, language, or domain solves the same problem, brought here | Local habit |
| Deletion | Solving it by removing or reusing what exists instead of adding | Elegance of new code |
| Moonshot | The shape you would build with no legacy and twice the ambition | Today's constraints, which it names |
| User-first | The experience of whoever calls, reads, or operates it | Implementation effort |

A moonshot candidate rarely wins whole. It earns its slot when its best idea survives as a graft.
