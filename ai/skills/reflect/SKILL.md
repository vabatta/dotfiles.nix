# Reflect

Use after a non-trivial task, a user correction, or a reusable workflow has
emerged. Skip one-off work that is already covered.

1. Capture the current conversation or use the host-provided transcript.
2. Review it through judgment, tooling, and divergent lenses. Use independent
   reviewers when the host supports delegation.
3. Synthesize Accepted, Rejected, and Backlog findings.
4. Move advice that should be enforced by a check, script, or type into the
   structural backlog instead of a prose edit.
5. Apply only approved changes. Inspect and verify every resulting artifact.

Reviewers must not edit files. Their findings are evidence, not authority.
