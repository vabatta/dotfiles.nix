# Ideas

**Pick when:** the candidates are not code: approaches to a problem, plans, product or feature ideas, names, file or config formats, PR templates, or UI concepts as text or sketches.

- **Candidate:** one page per writer, with the idea, a concrete example of it in use, what it costs, and what it gives up.
- **Location:** one file per writer under `.agents/arena/<slug>/<N>.md`.
- **Default rubric:** how well it solves the stated problem, simplicity, cost to build, and surprise, meaning an angle nobody had listed. Add the user's own criteria first when they gave any.
- **Verify:** check the synthesis against each acceptance line, and name which candidate each surviving element came from.
- **Return:** the synthesized idea in the reply.
