# Bro

Restate the last message so it lands.

1. Find the point of the last message. Done when it fits in one sentence.
2. Rewrite it in short plain sentences, using the terms in the project glossary (see **domain-modeling**). With no glossary, use the plain words the user used. Done when every term matches the glossary or the user's own words.
3. Use plain words (see **simple-english** in pragmatic mode) and no jargon. Done when a reader outside the project can follow it and nothing from the original is lost.
