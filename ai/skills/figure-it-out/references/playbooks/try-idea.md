# Try a risky idea

**Pick when:** nobody knows if an approach works: a new library, unknown feasibility, a UI that has to be felt.
**Chain:** prototype, assess
**Journey:** yes
**Done looks like:** the question has an answer from running code, and the prototype is deleted.

## Steps
1. Write the one question and the kill criterion.
2. **prototype**. Out: the verdict block with evidence.
3. **assess** the result against the kill criterion. Out: do, don't, or conditional.
4. Do → continue with change-code, carrying the constraints the prototype found.

## Watch for
- A prototype that grows into the real code: rebuild it properly through change-code.
- Two or more designs to score side by side: that is the compare gate, which runs arena inside change-code.
