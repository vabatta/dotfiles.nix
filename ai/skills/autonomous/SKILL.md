# Autonomous

The user has stepped away and cannot answer, whether for a night or until the review at the end. The run is **figure-it-out** at standard rigor or higher, bounded by the contract below. Nothing here replaces its phases.

1. Write the contract to `.agent/runs/autonomous/<slug>/contract.md`: goal, done predicate per **plan-work**, scope (units and paths in, everything else out), cap (hours and attempts, default 8 hours), workspace, authorized actions, and the start commit (`git rev-parse HEAD`). The workspace is where the user said to work, such as a branch, worktree, or PR, else a new worktree on `autonomous/<slug>`. The current checkout is the workspace only when the user names it. Every artifact of the run uses the one `<slug>`. Authorized actions are the one-way steps the user allowed, such as push or open a PR, else none. Fill any missing part per **principle-never-block-on-the-human** and record it as an assumption. Done when the file holds all seven.
2. Enter the workspace, creating the worktree or branch when it is new. Take only the authorized actions. Park any other one-way door (migration, delete, publish, push, merge, spend, send) as a unit holding the decision and the exact command for the human. Done when the workspace is in place and the contract lists the one-way doors known so far.
3. Run **figure-it-out** from the contract through its Phase C. Step 5 replaces its Phases D and E at the end. Fan out through **delegate**, one worktree per writer. Log each fork, finished unit, pivot, and blocker as it happens per **show-me-your-work**, into `.agent/decisions/<slug>.tsv` with its `log.sh`. Commit each passing unit in the workspace, never a red one. Commit unsigned with `git -c commit.gpgsign=false commit`, since signing needs the human. Leave git config alone. Done when each landed unit has a row, a passing check, and a commit.
4. Stop at the first of: the done predicate holds, the cap is reached, or no unblocked unit is left. Low context is not a reason to stop. Every three landed units and after any compaction, refresh the handoff at `.agent/handoffs/<slug>.md` per **recall** handoff mode and confirm a fresh agent would pick the same next move. Park a unit that fails its check three times. Revert it, log `NEEDS MANUAL REVIEW` with the failure, and move on. Park a unit whose tool call needs an approval nobody can give. A check that cannot run or gives a wrong answer stops the run, since routing around it hides the failure. Done when passing work is committed and the stop reason is logged.
5. Hand back. Do each of these in the workspace, then run `bash scripts/check-handback.sh <slug>` (path relative to this skill's directory).
   - Write the handoff to `.agent/handoffs/<slug>.md` per **recall** handoff mode.
   - Run **accept-change** on the diff since the start commit against the contract, and save the verdict to `.agent/runs/autonomous/<slug>/verdict.md`.
   - Write the full report per **report** to `.agent/runs/report/<slug>.html`. When no change landed, skip it and say so in the reply.
   - Commit `.agent/` unsigned as `agent: <slug> record`.
   Lead the reply with a table of added, deleted, and net lines against the budget, and say the commits are unsigned so the human re-signs them before pushing or merging, and that an authorized push publishes them unsigned. An autonomous run always counts as ambitious, so run the reviewer from **show-me-your-work**. End with its Attention section, with flags ranked least-confident first, then parked units, then assumptions. Done when the script exits 0 and every parked unit is listed.
