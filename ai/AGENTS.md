# Global agent principles

These rules apply in every session:
- State the stack before writing code (load principle-use-before-build).
- State a net-added-line budget before writing code (load principle-laziness-protocol).
- Verify the real artifact before declaring done (load principle-prove-it-works).
- On execution work, decide and proceed (load principle-never-block-on-the-human).
- Log each fork, finished unit, pivot, and blocker as it happens (load show-me-your-work).
- After a context summary, or in a fresh session that continues earlier work, rebuild the state before acting (load recall).
