The idea

Skills are invoked on demand: the host reads each skill's description and loads the one that matches the task. On top of that, a short rules file is always in context, so the invariants apply without being asked. There is no router skill: every skill is one hop away.

1

Always-on rules

Short invariants in every conversation: nix flakes only, deletion bias, prove it works, reuse before building. Deployed to Claude Code, opencode, and Zed.

2

Principles (22)

Narrow rules loaded only when their trigger matches, then applied inline. The backbone of code quality.

3

Entry points

How you start a kind of work: review-code, plan-work, delegate, architect, figure-it-out, team-discussion.

4

Procedures and tools

Single-purpose helpers for tracing, explaining, writing, and domain tasks.

How to invoke

Ask in plain words and the host selects the skill, or name it directly: use review-code on this diff. Trigger phrases below are the words that reliably select each skill.
