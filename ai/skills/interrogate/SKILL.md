# Interrogate

Use independent reviewers when the change is contested, cross-cutting, or easy
to get subtly wrong.

1. State the goal, constraints, and review rubric.
2. Give each reviewer the same grounding and a distinct lens.
3. Prevent reviewers from editing files.
4. Read every finding and verify it against the actual artifact.
5. Classify findings as Act on, Consider, Noted, or Dismissed.
6. Apply only findings that affect the stated goal and have evidence.

Use the host's delegation capability when available. One local review is valid
when independent delegation is unavailable.
