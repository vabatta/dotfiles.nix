# Try a risky idea

**Pick when:** nobody knows if an approach works or what it should be like: a new library, unknown feasibility, a shape to try in use, a UI, flow, or format that has to be felt.
**Chain:** prototype, assess
**Done looks like:** the question has an answer from running code, and the prototype is cleaned up as **prototype** says.

## Steps
1. Write the one question and the kill criterion.
2. **prototype**, in the variant that matches the question. Out: the verdict block with evidence.
3. **assess** the result against the kill criterion. Out: do, don't, or conditional.
4. Do → continue with change-code, carrying the constraints the prototype found.

## Watch for
- A prototype that grows into the real code: rebuild it properly through change-code.
- Two or more designs to score side by side: that is the compare gate, which runs arena inside change-code.
- Several open ideas, not one question: run **arena** with its ideas variant first, then prototype the winner.
